# SpendWise Financial Dashboard

## Project Description
SpendWise is a modern, responsive financial dashboard designed to help users track income, monitor expenses, and manage budgets efficiently. Built with semantic HTML, custom CSS (Grid/Flexbox), and interactive JavaScript components, it provides a clean and intuitive user experience for personal financial tracking.

## Technologies Used
* **HTML5:** Semantic document structure and layout.
* **CSS3:** Custom properties, CSS Grid, and Flexbox for responsive styling.
* **JavaScript (ES6+):** Interactive elements, dynamic transaction logging, and real-time balance calculation.
* **Git & GitHub:** Version control and source code management.
* **Netlify:** Continuous deployment and cloud hosting.
